# 1. 한눈에

모기 소리(음향) / 날갯짓(광학)을 **ESP32 마이크로컨트롤러 위에서 실시간 판별**하는 초경량 딥러닝 모델. 홍콩 FEHD·CHP 도심 야외 감시용을 목표로 12주간 개발·검증.

| 항목 | 값 |
|:---|:---|
| 아키텍처 | 1D-CNN, 3 conv + 2 FC (총 5층) |
| 파라미터 수 | 2,443개 (약 2.4천개) |
| 모델 파일 크기 (fp32) | **9.2 KB** |
| ESP32 추론 시간 | **67 ms / 샘플** (약 초당 15회) |
| ESP32 RAM 사용률 | 25 % (320 KB 중 80 KB) |
| ESP32 flash 사용률 | 7.5 % (4 MB 중 305 KB) |
| 판별 클래스 | 배경 / 모기 / 비모기 곤충 (3-class) |
| 배포 검증 | PyTorch = ESP32 **2,752 / 2,752 일치**, 로짓 최대 오차 2e-5 |

# 2. 모델 구조

**입력**: 1024 샘플 (8 kHz · 약 0.128초 분량 오디오)

| # | 층 | 출력 크기 | 파라미터 수 |
|:---:|:---|:---:|:---:|
| 1 | Conv1D (1→8, kernel=7) + BN + ReLU + MaxPool | 8 × 512 | 64 |
| 2 | Conv1D (8→16, kernel=5) + BN + ReLU + MaxPool | 16 × 256 | 656 |
| 3 | Conv1D (16→24, kernel=3) + BN + ReLU + MaxPool | 24 × 128 | 1,176 |
| — | Global Average Pooling | 24 | 0 |
| 4 | Fully Connected (24→16) + ReLU | 16 | 400 |
| 5 | Fully Connected (16→3) | 3 | 51 |

**출력**: 세 클래스 점수 [배경, 모기, 비모기 곤충]

- **얕고 좁은 설계** (ResNet-18 대비 층수 1/4, 채널폭 1/40) → ESP32의 320 KB SRAM 안에서 여유롭게 동작.
- 큰 physics-informed CNN 교사 모델(W6, 약 33 K 파라미터)로부터 **지식 증류(Knowledge Distillation)** 를 거쳐 13배 압축.
- 배포 시 BatchNorm을 Conv에 접어 넣어(**BN folding**) 순수 곱셈·덧셈만 남김 → 하드코딩 C 추론으로 이식.

# 3. 학습 데이터

세 개의 공개 데이터셋을 조합. 실험실·야외·검증용의 서로 다른 특성.

| 데이터셋 | 종류 | 특성 | 활용 |
|:---|:---|:---|:---|
| **Wingbeats** (Potamitis 2018) | 광학 (레이저 센서) | 모기 6종, 실험실 환경 | 학습용 모기 |
| **HumBugDB** (Kiskin 2021) | 음향 (스마트폰 마이크) | 모기 + 배경 소음, 실제 야외 녹음 | 학습용 모기 + 배경 |
| **UCR InsectWingbeat** (Chen 2014) | 광학 (레이저+포토트랜지스터) | 모기 4종 + 파리 2종 | 검증용 (모기 vs 비모기 가능성 입증) |

**세 클래스로 통합**: 배경 / 모기 / 비모기 곤충.

## 3.1 학습 과정에서 배운 것

- 원시 데이터의 표본 편향(**Wingbeats가 학습셋의 79%**)이 모델을 "이 소리가 Wingbeats 특유의 실험실 잡음인가?"만 학습하게 만드는 **도메인 지름길** 을 유발.
- 이를 잡기 위해 Wingbeats를 14% 수준까지 서브샘플링 + 물리 정보 기반 아키텍처(W6 교사) 도입 → 광학 vs 음향 사이 정확도 격차를 **28 → 11 % 포인트** 로 축소.

# 4. 성능

## 4.1 종합 정확도

전체 테스트셋 (89,866 샘플) 및 stratified 서브셋(2,752 샘플, ESP32 실측) 기준.

| 지표 | 값 |
|:---|:---|
| 전체 테스트셋 정확도 | 81.2 % |
| 모기 F1 점수 | **0.895** |
| ESP32 실측 정확도 (stratified 2,752) | 70.2 % |
| ESP32 ↔ PyTorch 예측 완전 일치 | **2,752 / 2,752** |
| 로짓 최대 오차 | 2e-5 (부동소수점 노이즈 수준) |

> *stratified 서브셋 정확도가 낮은 이유:* 클래스별 1,000/1,000/752로 균등하게 뽑아 어려운 비모기 곤충 비중을 자연 분포보다 크게 늘렸기 때문. 자연 분포 기준 정확도는 81 %.

## 4.2 클래스별 세부 성능 (재현율 / 정밀도 / F1)

| 클래스 | 재현율 | 정밀도 | F1 |
|:---|:---:|:---:|:---:|
| **모기** | 89.9 % | ≈ 89 % | **0.895** |
| **배경** | 69.9 % | ≈ 80 % | 0.745 |
| **비모기 곤충** | 44.3 % | **≈ 5 %** | **0.087** |

## 4.3 세부 강점

1. **모기 인식은 신뢰할 수 있음** — 실제 야외 녹음(HumBugDB) 기준 재현율 84%. 모기 있으면 놓치는 일 적음.
2. **홍콩 관련 종에서 재현율 ≥ 81 %** — *Ae. aegypti*, *Ae. albopictus*, *Cu. quinquefasciatus* 모두 감시 목표 종.
3. **노이즈에 강함** — 배경 잡음 SNR 0 dB 조건에서도 76 % 정확도 유지 (교사 모델 62 % 대비).
4. **PyTorch = 칩 결과 완전 일치** — 실기기에서도 "노트북에서 본 정확도 그대로" 재현. 배포 갭 0.

## 4.4 세부 한계

1. **비모기 곤충 클래스는 사실상 미해결** (F1 0.087):
   - 정밀도가 약 5%로 매우 낮음 = 칩이 "비모기 곤충"이라고 판정할 때 **95% 확률로 오답**.
   - 원인: 학습 데이터에 **광학 비모기 곤충(깔따구·파리 등) 샘플이 거의 없음**.
   - 결과: 실전에서 곤충 판별을 신뢰하기 어려움 → **오경보 위험**.
2. 학습 데이터의 대부분이 **실험실 조건** — 진짜 야외 노이즈·바람·먼지 환경에서의 성능은 미검증.
3. 실제 마이크·광학 센서 → ESP32 입력 파이프라인 아직 미구현 (현재는 호스트에서 데이터를 시리얼로 주입해 검증).
4. 일부 종(*An. gambiae s.s.*)은 재현율 1 % 미만 — 다만 사하라 이남 종이라 홍콩 배치에 영향 없음.

# 5. 하드웨어 · 배포

| 항목 | 값 |
|:---|:---|
| 타깃 칩 | ESP32 (Xtensa LX6, 240 MHz, 4 MB flash, 320 KB SRAM) |
| 개발 보드 | ESP32-CAM + CAM-MB 프로그래머 (총 원가 ≈ 4 USD) |
| 추론 방식 | 하드코딩 C++ (외부 ML 런타임 없음, TFLite Micro 미사용) |
| 순 가중치 크기 | 9.17 KB (fp32) → INT8 양자화 시 이론값 2.3 KB |
| 전체 펌웨어 .bin | 305 KB |
| 추론 지연 | 67 ms (칩 순수 계산) / 159 ms (USB 통신 포함) |
| 처리 속도 | 초당 약 15회 판별 |
| 실시간성 | 8 kHz × 1024 샘플 = 128 ms 데이터 도착 주기 → 67 ms 처리로 **여유 50 %** |

**결론: 실시간 판별 가능한 폭 확보. USB 시리얼 대신 실 마이크 연결 시 훨씬 더 여유.**

# 7. 개선 방향 (우선순위)

## 7.1 최우선 — 광학 비모기 곤충 데이터 확보

- **문제**: 비모기 곤충 클래스 F1 0.087 (사실상 미해결).
- **원인**: 광학 센서로 촬영된 깔따구·파리·나방 등 데이터가 공개 소스에 거의 없음. 학습셋에 실질적으로 "비모기" 예시가 부족.
- **해결 후보**:
  1. eBoss (독일 라이프치히), KInsecta 프로젝트, 유타대학의 optical insect sensor 팀 접촉 (담당자 파악 완료).
  2. 실험실에서 자체 광학 센서 구축 후 홍콩 현지 곤충 종 수집.
  3. UCR InsectWingbeat의 파리 데이터(현재 검증용)로 모델 fine-tuning 시도.
- **기대 효과**: 비모기 F1 0.09 → **최소 0.5 이상**, 오경보 대폭 감소.

## 7.2 실제 센서 → ESP32 파이프라인

- **현재 상태**: 데이터는 호스트에서 시리얼로 주입해 검증. 실 센서 미연결.
- **필요 작업**: 마이크(MEMS I2S) 또는 광학 센서 → ADC/I2S 드라이버 → 1024 샘플 링버퍼 → 모델 입력.

## 7.3 INT8 양자화

- 현재 fp32. INT8 양자화 시 **파일 크기 4배 축소** (9.2 KB → 2.4 KB), 추론 속도도 개선.
- 정확도 손실은 보통 1–2 % 포인트 이내 예상.

## 7.4 현장 데이터 수집 + 재학습 (Active Learning)

- 실제 홍콩 야외 배치 후 모호한 샘플 → 서버에서 라벨링 → 주기적 재학습.
- 도메인 지름길 문제를 근본적으로 해결하는 유일한 방법.

## 7.5 모델 규모 확대 여지

- 현재 RAM 여유 75 %, flash 여유 92 %. **모델을 3–5배 키워도 여전히 여유**.
- 정확도 부족한 클래스(비모기 곤충)를 상대로만 선택적으로 파라미터 증설 가능.

# 8. 요약 문장

> **9 KB짜리 딥러닝 모델이 4달러 ESP32 칩 위에서 초당 15번 모기 판별. 모기 인식(89 %)과 실기 검증(PyTorch와 완전 일치)은 실전 배치 수준이나, 비모기 곤충 오경보(정밀도 5 %) 문제는 광학 비모기 데이터셋 확보가 해결 열쇠.**
